Flask Example

The starting point for a new flask application

What you find here:

Modular Structure

There are many poorly structured examples on the web.

This example includes a best practices setup with blueprints to enable smooth scaling of apps.

Flask Extensions

Several flask extensions are included to handle the common tasks of web developers. The included extensions are flask-login, flask-assets, flask-WTF and flask-mongoengine.

Tests

Example tests, built with py.test, are included in to demonstrate how to test a flask app.

Common Libraries

The CSS and JS files for Bootstrap are included, along with jQuery.
